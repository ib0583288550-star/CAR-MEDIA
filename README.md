# Car Media

אפליקציית Android בעברית לנגן מדיה ברכב: אנשי קשר, חיוג מהיר ומסך בדיקת Bluetooth.

## דרישות
- Android 8.0 ומעלה (minSdk 26)
- הרשאת אנשי קשר להצגת אנשי הקשר המקומיים
- Bluetooth פעיל לצורך צימוד דרך הגדרות Android

## בנייה
הפרויקט נבנה באמצעות GitHub Actions ומפיק APK מסוג debug.

## חשוב לגבי דיבורית
Android אינו מבטיח שכל נגן מדיה יכול לפעול כלקוח דיבורית Bluetooth. חיוג ושמע דו-כיווני דורשים תמיכה של מערכת המכשיר בפרופיל Bluetooth HFP Client (ולעיתים גם PBAP). הגרסה הראשונית מציגה אנשי קשר מקומיים ומעבירה חיוג לאפליקציית הטלפון; היא אינה מנתבת בעצמה את שמע השיחה ואינה כוללת עדיין מסך שיחה מלא.
